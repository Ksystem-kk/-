# QRコード照合

Android端末のカメラでQRコードを2つ読み取り、データが完全一致するかを確認するアプリです。読み取れるデータは、`KKNI`で始まる全19文字または全20文字に限られます。1つ目のコードが条件に合わない場合は読み取りを続け、2つ目の条件に合うコードを読み取ると一致・不一致を表示します。

## エミュレーターで実行

1. Android Studioをインストールして起動します。
2. Android StudioのSDK Managerで、**Android SDK Platform 35**と**Android Emulator**をインストールします。JDK 17も利用できる状態にしてください。
3. Device Managerを開き、仮想端末（AVD）を作成します。カメラ入力を使う場合は、AVDの設定で前面または背面カメラを利用可能なカメラに設定してください。
4. このリポジトリをAndroid Studioで開き、Gradle同期が完了するのを待ちます。
5. Device Managerから作成したAVDを起動し、Android Studioの実行先として選択してアプリを実行します。初回起動時にカメラ権限を許可してください。
6. パソコンの画面にQRコードを表示し、エミュレーターのカメラ映像に映します。最初のQRコードを読み取ったら、いったんカメラから外し、次のQRコードを映してください。

一度目の比較を試す例として、`KKNI123456789012345`（19文字）と`KKNI123456789012346`（19文字）のQRコードを用意します。同じ値を2つ読み取ると一致し、異なる値ならエラー表示と音で知らせます。QRコード画像は任意のQRコード生成ツールで作成してください。

AVDのカメラ設定やホスト画面上のQRコードの読み取りは、使用する仮想端末・ホスト環境により異なります。カメラ映像が使えない場合は、AVDのカメラ設定を確認するか、カメラ付きの実機で実行してください。

## ビルドとテスト

- コマンドラインでのビルド: `./gradlew :app:assembleDebug`
- 単体テスト: `./gradlew :app:testDebugUnitTest`
- 単一テストクラス: `./gradlew :app:testDebugUnitTest --tests 'com.example.qrcodematcher.QrCodeValidatorTest'`
- lint: `./gradlew :app:lintDebug`

## 構成

- `MainActivity`がCameraXのプレビューと画像解析を管理し、ML KitでQRコードだけを読み取ります。
- `QrCodeValidator`が読み取った生データの先頭文字と全体の文字数を判定します。条件を通過した値だけを1つ目として保持し、次の有効な値と完全一致で比較します。
- 1つ目を読み取った後、誤って同じQRを照合しないよう、カメラからQRが一度見えなくなってから2つ目を受け付けます。
- 2つの有効なQRの内容が一致しない場合は、画面に赤字でエラーを表示し、エラー音を鳴らします。
- 読み取ったデータは端末内にも保存せず、比較結果だけを画面に表示します。
